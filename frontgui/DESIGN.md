## 5. 仅供运行的示例（可全部替换）

- 颜色：蓝色主色 `#2563eb`、浅灰页面 `#f8fafc`、白色表面、深色文字 `#0f172a`。
- 语义 token：`primary`、`on-primary`、`page`、`surface`、`foreground`、`muted`、`border`、`success`、`error`、`info`、`skeleton`。
- 字体：沿用已安装的 Noto Sans SC，配合系统字体回退；正文使用 Tailwind `text-base`，辅助文字 `text-sm`，标题 `text-3xl`。
- 间距和断点：Tailwind 默认刻度；首页最大宽度 `max-w-4xl`，窄屏单列，`md` 起双列，文档页面自然滚动。
- 圆角：`rounded-control` 为 8px，`rounded-card` 为 12px；阴影使用 `shadow-card`。
- 示例组件：Element Plus 按钮 / 输入框、成功 / 错误 / 提示 Toast、骨架卡片和骨架行。
- 交互：按钮具备 hover、focus、disabled 状态；Toast 进入/退出约 200ms；骨架以透明度变化表示加载，减少动态效果时停用动画。
- 可访问性：输入有标签，Toast 使用状态播报，骨架隐藏装饰内容并提供加载说明。

## 6. 从设计到实现

1. 先填写并确认上面的项目设计决策。
2. 在 `src/styles/tokens.css` 中替换示例值、按需调整 token 名称。
3. 在 `src/styles/element-plus.css` 中维护 Element Plus 的变量映射。
4. 页面优先使用语义工具类，例如 `bg-surface text-foreground rounded-card`，避免重复硬编码同类视觉值。
5. 删除或替换首页示例，并检查桌面、窄屏、键盘焦点与减少动态效果。

本文档不会自动生成 CSS。修改设计后，需要同步更新 token、映射和组件。
